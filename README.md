# Maker-ESP32 四轮差速小车

首次安装或换电脑：先看 [Arduino IDE 环境配置与上传教程](docs/Arduino环境与上传.md)，包含版本、开发板包、厂家库、工具菜单设置和常见问题。准备发布请看 [GitHub 上传说明](docs/GitHub上传说明.md)。对接其他客户端请看 [HTTP 接口说明](HTTP接口说明.md)。

GitHub 发布包的 `PS3_HOST_MAC` 已留空，网页可直接使用；启用手柄前需在 `CarConfig.h` 填入自己的手柄背面配对码并重新上传。下文编译大小来自已填写配对码的本地完整功能配置，留空时大小可能不同。

小车自己建立 Wi-Fi 热点并提供控制网页。电脑、手机、平板连接热点后访问固定地址即可，不需要路由器、互联网或额外客户端。PS3 手柄和网页共用 `MotionControl::submit()` 运动接口，统一驱动四个电机。

## 更新：车轮速度百分比档位（2026-09-30）

- 手柄和网页的车轮默认速度为 **80%**。百分比表示 PWM 输出档位，不是实测车速，也不保证与实际速度成正比。
- 手柄：L1+R1 激活后，每按一次 **□ 方块键**增加一档、每档20%，循环 **80% → 100% → 20% → 40% → 60% → 80%**。按住不连跳；激活后需先松开 □，再按下切档。重新激活、重新连接或全部停车后恢复默认80%。
- 网页：直接选择 **20%、40%、60%、80%、100%**，不需要理解0～255的数值；激活前后均可选档，行驶中切换随下一条运动指令生效。页面初次打开或刷新为80%，退出再激活保留本页面所选车轮档位。
- **△ 三角键**与网页新增电机切档按钮继续控制 GPIO32 电机的关闭/1/2/3档，与车轮速度独立。重新激活时新增电机仍从关闭开始。
- 手柄接管后，网页禁用车轮和新增电机档位操作，并显示手柄当前车轮百分比档位。

## 更新：网页与手柄直接切换控制权

- 网页点 **激活网页控制**（手柄控制时显示 **切换到网页控制**），可直接从手柄接管，不必先按手柄 ×；电脑仍可用 Ctrl+Enter。切换时先停止车轮并关闭新增电机，随后才接受本页面的新操作。
- 手柄两个摇杆回中、松开肩键后，重新按 **L1+R1** 可从网页接管；先关闭全部电机，车轮档位恢复80%。未激活的手柄推摇杆、按 △ 或 □ 不会影响网页。
- 被接管的网页会退出控制，不自动抢回；需再次点切换按钮。网页延迟到达的旧指令、退出请求不会覆盖新的控制者。
- 明确按 **×、Esc、全部停车 / 退出** 仍是全局停车。自动失焦、切后台或通信故障只释放该网页自己的控制会话。

## 新增：GPIO32 MOSFET 电机三档控制（2026-09-30）

- 手柄：摇杆回中按 **L1+R1** 激活，随后每按一次 **△ 三角键**，新增电机依次 **关闭 → 1档 → 2档 → 3档 → 关闭**。按住不连跳；进入遥控时已按住 △，需松开后再按。
- 网页：先点 **激活网页控制**（手柄控制时显示 **切换到网页控制**），再点新增电机的 **切换档位**，循环顺序相同。页面显示档位；手柄接管后显示手柄档位并禁用网页切档。
- 松开行驶键、摇杆回中只停止车轮，新增电机保持当前档位。**×、Esc、网页“全部停车 / 退出”**关闭全部电机。
- 上电、重新激活网页、手柄接管、当前控制源断连或超时均从关闭开始，不恢复旧档位。手柄在线但未激活时不会占用网页控制。
- 网页后台、失焦、通信失败时发送带本页面会话编号的 **`/release`**，只释放该会话，不抢停已接管的手柄或另一个网页。明确按停车仍使用全局 **`/stop`**。

GPIO32 的 S 脚输出高电平导通的 **5kHz、8位 PWM**，使用第九个独立通道，不影响 M1～M4。默认档位配置在 `CarConfig.h`：

```cpp
constexpr uint8_t AUX_MOTOR_PIN = 32;
constexpr uint8_t AUX_MOTOR_PWM[4] = {0, 85, 170, 255};
```

四个值分别是关闭、约33%、67%、100%占空比，与车轮速度档位独立。若一档带载无法起转，可根据电机及负载提高一档值；程序不会自动全速起转。

接线按用户提供的高电平导通模块：32口 S 接模块信号输入，5V/G 接模块对应供电/地，电机接模块负载输出。S 是 **3.3V 逻辑**，模块需支持 3.3V 触发、5kHz PWM 和电机感性负载并具备续流保护；仅凭 AOD242 型号不能确认模块的外围电路。程序初始化尽早拉低 S，复位/烧录期间默认关闭仍需模块自身输入下拉。板载5V电源的启动/堵转电流余量需实测，软件不会把5V升到6V。

HTTP 新增 `/move` 可选参数 **`aux=0..3`**，以明确档位随心跳续期，重复请求不会重复加档。省略时保持尚未超时的档位，超时后归零。`/status` 新增 `aux_level`、`aux_pwm`。完整协议见 `HTTP接口说明.md`。

## 1. 上传程序

在 Arduino IDE 打开本目录的 **carplay.ino**，保持同目录四个 `.h` 文件一起保存。原来的 `motorTest/motorTest.ino` 保留为独立电机测试工程。

- 开发板包：**esp32 by Espressif Systems 3.3.2 / 3.3.2-cn**。
- 开发板：**ESP32 Dev Module**（经典 ESP32，不能选择 S3/C3/S2）。
- Flash Size：**4MB**。
- Partition Scheme：**Huge APP (3MB No OTA/1MB SPIFFS)**。
- 串口监视器：**115200**。
- 手柄库：厂家 **emakefun_esp32_ps3 2.0.1**，本机已安装到 `Documents/Arduino/libraries/emakefun_esp32_ps3`。库显示名称仍为 `PS3 Controller Host`，请确认版本为 **2.0.1**，不要另装库管理器中的旧版。

本机当前安装的开发板包是 3.3.2-cn，本次已用该版本编译验证，记录见第7节。厂家 PS3 库验证范围为 2.0.17～3.3.6，推荐 3.3.2 / 3.3.2-cn；上传前请在 IDE 确认版本和分区选项。

如果编译提示 `Sketch uses ... (126%)`、`Maximum is 1310720 bytes` 或 `text section exceeds available space in board`，表示仍选用了默认的约 1.25MB 程序分区。在 **工具 → Partition Scheme（分区方案）** 中选择 **Huge APP (3MB No OTA/1MB SPIFFS)**，同时保持 **Flash Size = 4MB (32Mb)**，再点击验证/编译。选择后程序区上限应显示为 **3145728 bytes**。命令行的编译选项不会自动更改 Arduino IDE 下拉菜单，需在 IDE 内选择一次。

若使用 PS3，在 **CarConfig.h** 中填写手柄背面的配对码：

```cpp
constexpr char PS3_HOST_MAC[] = "02:00:01:23:45:67"; // 替换成自己的号码
```

这是资料中 emakefun 手柄的目标主机配对码，不是任意手柄自身的蓝牙 MAC。留空时仍可使用网页控制。

## 2. 连接小车热点并打开网页

1. 上传完成，给小车供电。
2. 电脑或手机连接 **Carplay-ESP32**，密码 **carplay123**。
3. 在浏览器地址栏输入 **http://192.168.4.1**，即可看到小车控制网页。

不需要填写家里 Wi-Fi 的名称和密码。显示“无互联网连接”是正常的，请保持连接小车热点。电脑需要有可用的无线网卡并开启 Wi-Fi；也可直接使用手机。

热点名、密码和地址可以在 `CarConfig.h` 中修改；`WIFI_SSID` / `WIFI_PASSWORD` 指的是**小车创建的热点**。密码必须为 8～63 个字符。默认地址为 `192.168.4.1`，客户端地址由小车自动分配。

## 3. 网页、键盘和触屏操作

先点击 **激活网页控制**（手柄控制时显示 **切换到网页控制**），电脑也可按 **Ctrl + Enter**。即使手柄正在遥控，也可直接切换；切换时全部电机先关闭。操作前先松开运动键，不需要一直按住组合键。

| 操作 | 小车运动 |
| --- | --- |
| W 或 ↑，手机按住“前进” | 前进 |
| S 或 ↓，手机按住“后退” | 后退 |
| A 或 ←，手机按住“左旋” | 原地左旋 |
| D 或 →，手机按住“右旋” | 原地右旋 |
| 选择20%、40%、60%、80%、100% | 设置车轮速度档位，默认80%；激活前后均可调整 |
| 松开运动键或触屏按钮 | 发送零速度停车指令，仍保持网页控制模式 |
| Esc 或点击“全部停车 / 退出” | 关闭全部电机并退出模式，需要再次激活 |

**旋转优先**：同时按 W 和 D 时原地右旋，不叠加成弧线；相反方向按键互相抵消。网页用五个百分比档位替代原来的速度滑块，**默认80%**。20%、40%、60%、80%、100%分别对应 PWM 51、102、153、204、255；百分比不是实测车速。页面退出、重新激活时保留所选车轮档位，刷新页面恢复80%；重新激活时新增电机归零。

手柄遥控模式激活时，网页显示手柄的车轮档位，暂时禁用网页档位操作，但 **切换到网页控制** 按钮仍可使用。档位显示来自 `/status` 的 `ps3_speed_percent`，表示手柄满推摇杆时的输出比例。

切换窗口、切换浏览器标签页、网页进入后台时，网页会退出模式并发送带会话编号的 `/release`；只有本页面仍占有控制权时才关闭车轮与新增电机，回来后需要重新切换控制。关闭网页会尽力发送释放请求。网页激活时每约 100 毫秒刷新一次包含会话编号和档位的命令；浏览器意外退出或网络中断时，固件收到的最后一条网页命令会在约 500 毫秒后失效，旧会话失效后不能继续使用。停止输出后电机可能因惯性继续转动。

所有页面资源都在小车固件内，离线可用。支持具有 Pointer Events 的现代桌面和手机浏览器。多个网页均可打开，但同一时刻只有一个受管理的网页会话控制；另一个网页明确切换后，旧网页会话失效。

## 4. PS3 手柄操作与控制权

1. 按手柄中间 PS 键连接。
2. 两个摇杆回中，松开肩键后按一次 **L1 + R1** 激活遥控模式；可直接从网页接管，切换时先关闭全部电机，之后可以松开肩键。
3. **左摇杆向上前进、向下后退**；左摇杆左右方向不使用。
4. **右摇杆向左原地左旋、向右原地右旋**；右摇杆上下方向不使用。
5. 默认车轮档位为 **80%**。每按一次 **□ 方块键**增加20%，100%后回到20%；按住不连跳，激活时已按住需先松开再按。重新激活、重新连接或全部停车后恢复默认80%。
6. 摇杆推得越远，输出越大；推满时达到当前档位上限。两个摇杆同时操作时，**右摇杆旋转优先**；右摇杆回中后，左摇杆恢复前后控制。
7. 每按一次 **△ 三角键**，新增电机依次关闭 → 1档 → 2档 → 3档 → 关闭，与 □ 控制的车轮档位独立。
8. 两个控制轴回中后停止车轮，但仍保持遥控模式和新增电机档位。按 **×** 关闭全部电机并退出遥控模式。

方向键不再承担运动操作。摇杆偏离中心时按组合键不会激活，需回中后重新按一次。停止、断连或超过 500 毫秒没有有效数据包后会退出遥控模式；恢复信号后不会自动恢复运动，需重新按 L1 + R1 激活。

遥控模式激活后，即使摇杆回中也会保持控制权，原网页的运动请求返回409；旧网页会退出模式，不会自动重新接管，也不会发送全局停车打断新控制者。点 **切换到网页控制** 可明确接回网页，不需要先按手柄 ×。手柄失去控制权后，摇杆与 △、□ 不会影响网页，重新按回中的 L1+R1 才会接管。任何时候调用 `/stop`、按手柄 × 或按网页全部停车按钮，都可以关闭全部电机、清除会话并退出遥控模式。

手柄默认车轮档位由 `CarConfig::PS3_DEFAULT_SPEED_PERCENT = 80` 配置，死区为 `15`。摇杆输入先归一化到-255～255，再乘以当前百分比；默认80%时满推输出 PWM 204，轻推按比例减小。停止与模式变化均在独立电机任务的下一个约 10 毫秒周期内落实，不依赖 HTTP 请求处理速度。丢弃被接管前的旧命令，不会在退出手柄模式后自动恢复旧动作。

默认80%档位下，网页原地左旋或手柄向左满推时输出左侧-204、右侧+204，右旋相反，左右两侧同时反向转动。100%档位对应 PWM 255，电机获得接近驱动供电的电压，并非恒功率控制；本车输入12V，测试前确认车轮电机额定电压匹配，先架空车轮测试。GPIO32新增电机档位仍为0/85/170/255，不随车轮档位改变。

## 5. 保留的 HTTP 接口

网页使用下面这些接口；你也可以从自己的程序调用。

| 动作 | 路径，前缀为 http://192.168.4.1 |
| --- | --- |
| 明确切换到 Wi-Fi 控制，返回新的会话编号 | `POST /claim` |
| 前进 | `/move?session=<返回的编号>&speed=120&turn=0` |
| 后退 | `/move?session=<返回的编号>&speed=-120&turn=0` |
| 原地左转 | `/move?session=<返回的编号>&speed=0&turn=-120` |
| 原地右转 | `/move?session=<返回的编号>&speed=0&turn=120` |
| 前进右转弧线，仅直接 API | `/move?session=<返回的编号>&speed=120&turn=60` |
| 前进 1 秒 | `/move?session=<返回的编号>&speed=120&turn=0&ms=1000` |
| 停车并退出遥控模式 | `/stop` |
| 仅释放本会话，不抢停新的控制者 | `/release?session=<返回的编号>` |
| 车轮停止，新增电机 1档 | `/move?session=<返回的编号>&speed=0&turn=0&ms=500&aux=1` |
| 查询状态 | `/status` |

`/claim` 只支持 POST，无需参数。它关闭全部电机、退出手柄模式，返回正整数 `session` 与 `valid_ms:500`；之后每约100毫秒携带该编号续发 `/move`。手柄接管、全部停车、超时、所有 Wi-Fi 客户端断开或另一次 `/claim` 都会令旧编号失效；不得自动重新 `/claim` 抢回控制权。

`/move`、`/stop`、`/release` 支持 GET 和 POST（URL 或表单参数，不接受 JSON 请求体）。`speed` 和 `turn` 必填，为 -255～255 的整数。`ms` 默认 500，可指定 100～2000；持续运动需重复发送。网页固定使用 500 毫秒，不受直接 API 的其他请求参数影响。兼容的无 `session` 运动请求仅在没有有效网页会话、没有手柄遥控占用时可用；推荐新终端采用会话协议。

默认80%是手柄及网页的交互默认值，**不会把直接 HTTP 请求统一限制到80%**；在有效会话中请求 `speed=255&turn=0` 仍可输出100%。

返回码：200 成功、400 参数错误、409 手柄占用或会话失效、405 不支持的方法。`/status` 返回 `source`、`left`、`right`、`ps3_online`、`remote_mode`、`ps3_speed_percent`、`wifi_session`、`aux_level`、`aux_pwm` 和热点 `ip`；左右轮速度是目标 PWM，不是编码器读数。`ps3_speed_percent` 仅描述手柄档位，不代表网页或直接 HTTP 指令的档位。`wifi_session` 为0表示没有有效网页会话；会话编号用于防止旧请求覆盖新控制者，不是登录凭证。`/stop` 返回表示已接收指令，不是机械车轮已经停转的确认。

## 6. 电机对应关系与方向校准

| 电机 | 车轮 | GPIO，沿用原 motorTest |
| --- | --- | --- |
| M1 | 左前 | 27 / 13 |
| M2 | 右前 | 4 / 2 |
| M3 | 左后 | 17 / 12 |
| M4 | 右后 | 14 / 15 |

M1、M3 使用左侧速度；M2、M4 使用右侧速度。差速公式是左侧 `speed + turn`、右侧 `speed - turn`；超过 255 时按比例缩放。四轮差速车不能横向平移。

原地左旋时 M1/M3 后退、M2/M4 前进；原地右旋时 M1/M3 前进、M2/M4 后退，四个轮子均输出非零 PWM。若实车只有两轮运动，先架空车轮检查单独前进、后退是否都能驱动四轮，再记录不转的 M 编号，以区分接线/驱动/起转负载问题与指令问题。`tests/motor_driver_test.cpp` 将实际混合与驱动代码连接到模拟 LEDC，验证两种控制来源及 1～255 的旋转输出；此测试不能代替硬件检查。

官方文字中的 M4 为 15 / 14，与现有测试程序顺序相反。本工程保留现有程序的引脚顺序，通过配置校准方向：

```cpp
constexpr int8_t MOTOR_POLARITY[4] = {1, 1, 1, 1}; // M1、M2、M3、M4
```

首次测试架空车轮、低速前进；哪只轮子朝反方向转，就把对应的 1 改为 -1。不要同时交换引脚和方向符号。Motor and IO Switch 需拨到电机侧，否则 M3、M4 不工作；电机通过 DC 口供电，电压需满足板卡和电机要求，USB 不代替电机电源。

## 8. 后续添加摄像头图传

可保留当前 Maker-ESP32 控车，另加厂家 ESP32S3-CAM（建议带 OV2640 的套件）或 ESP32-CAM V2。摄像头作为客户端连接 **Carplay-ESP32** 热点，电脑/手机也连同一热点，直接访问摄像头的 IP；视频不经电机控制接口转发。

厂家 S3 摄像头例程的图传地址为 `http://摄像头IP:81/stream`。摄像头 IP 需单独确定，不能占用小车的 `192.168.4.1`。这是扩展建议，当前固件尚未包含视频画面。ESP32-S3 不支持现有 PS3 所需的经典蓝牙，所以仍由当前主控接手柄。摄像头按其供电要求供电，不能直接接电机电源。
